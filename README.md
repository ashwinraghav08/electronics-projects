# Electronics Projects

Arduino/Elegoo builds covering sensors, motor control, displays, and access control. Each project lives on its own branch with code, wiring, and notes.

| Project | What it does | Branch |
|---|---|---|
| RFID Lock System | Grants or denies access by scanning RFID tags and driving a lock actuator | [rfid_locksystem](../../tree/rfid_locksystem) |
| Temperature-Controlled Fan | Reads temperature and adjusts fan speed with PWM | [temperature_controlled_fan](../../tree/temperature_controlled_fan) |
| Joystick Stepper | Controls a stepper motor's direction and speed with an analog joystick | [joystick-stepper](../../tree/joystick-stepper) |
| Temperature OLED Display | Shows live sensor readings on an OLED screen | [temperature_oled](../../tree/temperature_oled) |
| Water Level Detector | Detects water level with a sensor and triggers an alert | [water_level_detector](../../tree/water_level_detector) |
| Button LED | Intro build: digital input controlling an LED | [button_led](../../tree/button_led) |

**Tools:** C++ (Arduino), breadboarding, PWM, I2C/SPI peripherals
